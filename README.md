# Thai Household Income Dashboard

แดชบอร์ดวิเคราะห์ข้อมูลรายได้ครัวเรือนไทย แยกตามจังหวัดและกลุ่มเศรษฐกิจและสังคม
พัฒนาด้วย Python, Pandas, Streamlit และ Plotly สำหรับวิชา Data Visualization

## วัตถุประสงค์

- เปรียบเทียบรายได้แต่ละหมวดระหว่าง 77 จังหวัด
- เปรียบเทียบรายได้ระหว่างกลุ่มเศรษฐกิจและสังคม
- ดูองค์ประกอบรายได้ 7 หมวดย่อยที่ไม่ซ้อนกัน
- เปรียบเทียบรายได้ระหว่างปี พ.ศ. 2566 กับ 2568 ของจังหวัดที่เลือก

## ชุดข้อมูล

| รายการ | รายละเอียด |
|---|---|
| ไฟล์ | `data.xlsx` (Sheet `data`) |
| แหล่งข้อมูล | สำนักงานสถิติแห่งชาติ (ตามคอลัมน์ `source` ในไฟล์) |
| ขนาด | 15,400 แถว × 11 คอลัมน์ |
| ปี | พ.ศ. 2566, 2568 |
| จังหวัด | 77 จังหวัด |
| หน่วย | บาท (คอลัมน์ `unit`) และชื่อหมวดระบุว่าเป็นรายได้ต่อเดือน |
| ความครบถ้วน | ไม่มีค่าว่างใน `value` ไม่มีแถวซ้ำ ทุกค่าเป็นตัวเลข |

1 แถว = 1 ปี × 1 จังหวัด × 1 หมวดรายได้ × 1 กลุ่มเศรษฐกิจและสังคมย่อย
แต่ละจังหวัดในแต่ละปีมี 100 แถวพอดี (10 หมวดรายได้ × 10 กลุ่มย่อย)

### คอลัมน์

| คอลัมน์ | ความหมาย |
|---|---|
| `year` | ปี พ.ศ. |
| `province` | จังหวัด |
| `source_income1`–`source_income3` | หมวดรายได้ 3 ระดับ (ดูโครงสร้างด้านล่าง) ใช้ `source_income3` ระบุหมวดของแถว |
| `soc_eco_class1` | กลุ่มเศรษฐกิจและสังคมหลัก 4 กลุ่ม |
| `soc_eco_class2` | กลุ่มย่อย 10 กลุ่ม (อยู่ภายใต้กลุ่มหลัก) |
| `value` | มูลค่า (บาท/เดือน) |
| `unit` | หน่วย (`บาท`) |
| `attribute` | หมายเหตุค่าพิเศษ เช่น ค่า 0 จากการสำรวจตัวอย่าง หรือค่าที่ปัดเศษเป็น 0 |
| `source` | แหล่งข้อมูล |

### โครงสร้างหมวดรายได้ (ตรวจสอบกับข้อมูลจริงแล้ว)

```

├── รายได้ประจำ
│   ├── รายได้ที่เป็นตัวเงิน
│   │   ├── ค่าจ้างและเงินเดือน
│   │   ├── กำไรสุทธิจากการทำธุรกิจ
│   │   ├── กำไรสุทธิจากการทำการเกษตร
│   │   ├── เงินที่ได้รับเป็นการช่วยเหลือ
│   │   └── รายได้จากทรัพย์สิน
│   └── รายได้ที่ไม่เป็นตัวเงิน
```

ผลรวมของหมวดย่อยเท่ากับหมวดแม่ในทุกจังหวัด กลุ่ม และปี โดยคลาดเคลื่อนไม่เกิน ±2 บาทจากการปัดเศษ
แอปตรวจสอบโครงสร้างนี้ทุกครั้งที่โหลดข้อมูล และแสดงผลในส่วน "ผลตรวจสอบคุณภาพข้อมูล"

## วิธีใช้งาน

ตัวกรองอยู่ที่แถบด้านซ้าย ทุกตัวกรองมีผลกับ KPI กราฟ และตาราง

| ตัวกรอง | ผล |
|---|---|
| ปี (พ.ศ.) | เลือกปีที่วิเคราะห์ |
| จังหวัด | "ทุกจังหวัด" หรือจังหวัดเดียว กราฟเปรียบเทียบจังหวัดจะแสดงทุกจังหวัดและเน้นสีจังหวัดที่เลือก |
| หมวดรายได้ | เลือกได้ครั้งละ 1 หมวดตามโครงสร้างด้านบน หมวดที่มีคำว่า "(ยอดรวม)" รวมหมวดย่อยไว้แล้ว |
| กลุ่มเศรษฐกิจและสังคม (หลัก/ย่อย) | กลุ่มย่อยจะแสดงเฉพาะกลุ่มที่อยู่ใต้กลุ่มหลักที่เลือก |
| รีเซ็ตตัวกรอง | คืนค่าตัวกรองทั้งหมดเป็นค่าเริ่มต้น |

**KPI:** ปีที่เลือก · จังหวัดในผลลัพธ์ · จำนวนรายการที่ผ่านตัวกรอง · รายได้ของหมวดที่เลือก · ค่าสูงสุดในผลลัพธ์

**กราฟ:**
1. รายได้รายจังหวัด (สูงสุด 15 / ต่ำสุด 15 / ทั้งหมด)
2. รายได้ตามกลุ่มเศรษฐกิจและสังคม (กลุ่มที่อยู่นอกตัวกรองจะแสดงแบบจาง)
3. องค์ประกอบรายได้ 7 หมวดย่อย (เน้นสีหมวดที่อยู่ภายใต้หมวดที่เลือก)
4. เปรียบเทียบระหว่างปี (แสดงเมื่อเลือกจังหวัด)

**ตาราง:** แสดงรายการที่ผ่านตัวกรองด้วยชื่อคอลัมน์ภาษาไทย ดูทุกคอลัมน์รวม `source` และ `attribute` ต้นฉบับได้ในส่วนขยาย

## ข้อจำกัดของข้อมูล

- **ห้ามรวมทุกแถว** เพราะไฟล์มีทั้งหมวดยอดรวมและหมวดย่อย การรวมทุกแถวจะนับรายได้ซ้ำ แดชบอร์ดจึงแสดงค่าของหมวดที่เลือกครั้งละ 1 หมวด
- **ค่าเฉลี่ยไม่ถ่วงน้ำหนัก** เมื่อผลลัพธ์มีหลายรายการ (เช่น ทุกกลุ่มในจังหวัดเดียว) ค่าที่แสดงคือค่าเฉลี่ยอย่างง่ายของรายการ ไม่ใช่ค่าเฉลี่ยของประชากรทั้งจังหวัด เพราะไฟล์ไม่มีจำนวนครัวเรือนของแต่ละกลุ่ม
- **ค่า 0** มี 1,725 แถว ส่วนใหญ่มี attribute "ข้อมูลจากการสำรวจตัวอย่างมีค่าเป็น 0" บางกลุ่มในบางจังหวัดมีรายได้ทั้งสิ้นเป็น 0 (51 จาก 1,540 รายการ) ซึ่งอาจหมายถึงไม่มีครัวเรือนตัวอย่างในกลุ่มนั้น ค่าเหล่านี้ยังรวมอยู่ในค่าเฉลี่ยตามข้อมูลต้นฉบับ
- **ค่าติดลบ** มี 44 แถว เป็นค่าจริงในข้อมูล (เช่น กำไรสุทธิติดลบ) ไม่ได้ถูกแก้ไข
- ยังไม่ได้ยืนยัน URL ของชุดข้อมูลต้นทางเฉพาะ จึงอ้างอิงเพียงชื่อหน่วยงาน หากทราบลิงก์ชุดข้อมูลบนเว็บไซต์ของสำนักงานสถิติแห่งชาติ ควรเพิ่มไว้ที่นี่

## Deploy บน Streamlit Community Cloud

1. Push ไฟล์ทั้งหมดในตาราง "โครงสร้างโปรเจกต์" ขึ้น GitHub (รวม `data.xlsx`, `icons.py` และ `.streamlit/config.toml`)
2. ไปที่ [share.streamlit.io](https://share.streamlit.io) แล้วล็อกอินด้วย GitHub
3. เลือก **Create app** → Repository ของโปรเจกต์นี้ → Branch `main` → Main file path `app.py`
4. ใน Advanced settings เลือก Python 3.11 ขึ้นไป แล้วกด **Deploy**

แอปอ่าน `data.xlsx` จากโฟลเดอร์เดียวกับ `app.py` ด้วย path แบบสัมพัทธ์ จึงทำงานได้ทั้งในเครื่องและบน Cloud
โปรเจกต์ไม่ใช้ secrets หรือ API key
